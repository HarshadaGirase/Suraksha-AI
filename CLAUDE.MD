1. PROJECT IDENTITY
Name: SurakshaAI
One-liner: Voice Guardian & Fraud Rescue Network — bleeps live HinglishOTP-harvesting calls, and rescues victims AFTER money is stolen by preparingtheir 1930 complaint + bank freeze letter in under 4 minutes.

Positioning: Prevention tools protect only the installed few. SurakshaAIcovers the full lifecycle: DURING (intercept) + AFTER (rescue). The rescueflow is the hero and the anti-clone differentiator.

2. KEY DOMAIN FACTS (do not get these wrong in code or pitch)
1930 = India's national cyber-fraud helpline PHONE NUMBER (I4C/MHA).cybercrime.gov.in (NCRP portal) = its web companion. Victims file fraudcomplaints there; a complaint triggers money-trailing that freezes muleaccounts. Speed of reporting decides recovery.
The AI NEVER calls 1930 and NEVER auto-submits anything. No public APIexists; the portal requires the victim's own credentials — and we never takecredentials (hard rule). The product PREPARES documents; the VICTIM filesthem manually (minutes instead of hours). UI wording: "download", "ready tofile", "draft" — NEVER "submitted", "filed", "closed".
Mule accounts: stolen money hops through rented accounts within hours.This is why the product is built around the Golden Hour (target T+3:40 vs4–6 hours manual reporting today).

7.1 SANDBOX AUDIO INJECTION (critical implementation rule)
Generate each scenario as a SEQUENCE of MP3 segments (one per speaker turn,per §15 scripts). Never one mixed file.
Injection path: frontend decodes MP3 → AudioBuffer → resample to 16kHz monoPCM16 → chunk → send over WS#1 using the EXACT same code path as microphoneaudio. The pipeline cannot tell the difference — that is the point.
FORBIDDEN: playing the MP3 through speakers and re-capturing via mic(echo, feedback, quality loss, broken word-timestamps).
Audience playback: a parallel <audio> element plays the segment for theroom. The OTP segment's playback is muted at digit timestamps and a bleeptone plays instead; the transcript shows ••••••.
7.2 HALF-DUPLEX RULE (echo protection)
While agent TTS is playing, the frontend PAUSES sending mic/PCM chunks toWS#1; resume 300ms after playback ends.
Without this, the agent hears its own voice and loops forever.
Demo preference: headphones. Half-duplex makes open speakers safe.
7.3 AUDIO FORMAT
Browser mic = 44.1/48kHz → downsample CLIENT-side (AudioWorklet) to16kHz PCM16 mono BEFORE WS#1. AssemblyAI Realtime requires 16kHz.

11. RAG SPEC
Corpus (~60 chunks): RBI Master Direction on Customer Protection (Nov 2023)split on its numbered paragraphs; 1930/NCRP filing process; freeze-letterformat; NPCI UPI dispute rules.
Chunking: 300–500 tokens, ~60-token overlap, split on section boundaries.
Each chunk row: content, embedding vector(384), source, section_no, doc_date, doc_type.
Retrieval: top-3 cosine → prompt instruction: "Quote the citation as:RBI Master Direction on Customer Protection, Nov 2023, §{section_no}."
